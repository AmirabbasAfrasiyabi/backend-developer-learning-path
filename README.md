# 🚀 Back End Developer Learning Path

This repository is my personal archive for the **[Back End Developer Learning Path][playlist]** playlist by freeCodeCamp. It contains notes, code exercises, and projects from every course in the roadmap.

## 📌 Overview & Technologies Covered

The roadmap takes me from backend fundamentals to production-level topics:

* **Fundamentals:** Backend roadmap, Git & GitHub, APIs
* **Frontend & Full Stack Basics:** HTML, CSS, JavaScript, Node.js, MongoDB
* **Languages & Frameworks:** Python, Django
* **Databases:** SQL
* **API Development & Security:** REST APIs with Python, OWASP API Security Top 10, GraphQL
* **Quality & Architecture:** JavaScript testing with Jest, System Design
* **DevOps Basics:** Docker, Kubernetes

## 🚀 How to Use & Git Workflow

### 1. Clone the Repository

```bash
# Navigate to your projects directory
cd path/to/your/projects

# Clone the repository
git clone https://github.com/AmirabbasAfrasiyabi/backend-developer-learning-path.git

# Enter the project folder
cd backend-developer-learning-path
```

### 2. Basic Git Commands (For Saving Progress)

```bash
# Check status of modified files
git status

# Stage all updated files
git add .

# Commit changes with a message
git commit -m "Complete Python basics: lists and functions"

# Push changes to GitHub
git push origin main
```

### 3. Commit Message Examples

```bash
git commit -m "Add notes for Git and GitHub crash course"
git commit -m "Add SQL joins exercises"
git commit -m "Add Dockerfile for Django marketplace"
git commit -m "Mark course 06 (SQL) as completed in README"
```
